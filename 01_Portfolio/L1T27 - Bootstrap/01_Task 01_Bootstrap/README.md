# Online Art Gallery (Bootstrap Framework)

This project demonstrates the development of a responsive "Online Art Gallery" web page using the **Bootstrap 4** framework. It leverages Bootstrap's powerful grid system, pre-built components, and utility classes to create a visually appealing and adaptive layout that functions seamlessly across various device sizes. The project showcases a navigation bar, a dynamic art gallery grid, an image carousel, and a contact form within its structure.

## 🌟 Features

* **Bootstrap 4 Integration:**
    * **CDN Links:** Integrates Bootstrap's CSS and JavaScript (jQuery, Popper.js, Bootstrap JS) directly via Content Delivery Network (CDN) for easy setup and optimal loading.
    * **Responsive Meta Tags:** Includes essential `<meta>` tags for proper viewport scaling and responsive behavior across devices.
* **Responsive Navigation Bar:**
    * Utilizes Bootstrap's `navbar` component with `navbar-expand-lg`, `navbar-light`, and `bg-light` classes.
    * Features a `navbar-toggler` for a collapsible menu on smaller screens, ensuring excellent mobile user experience.
* **Dynamic Art Gallery Grid:**
    * Implements Bootstrap's responsive **Grid System** (`container`, `row`, `col-*-*`) to create a flexible and adaptive layout for displaying art pieces.
    * Each art piece is presented within a Bootstrap `card` component, complete with `card-img-top`, `card-title`, `card-subtitle`, `card-text`, and `btn` classes for clear presentation and user interaction.
    * Uses Bootstrap's **Flex Utilities** (`d-flex`, `flex-column`) for fine-tuning layout within cards and columns.
* **Interactive Image Carousel:**
    * Incorporates Bootstrap's `carousel` component to create a dynamic image slider, enhancing the visual appeal and showcasing featured artworks.
* **Responsive Footer with Form:**
    * The footer includes an image and a **Bootstrap Inline Form** (`form-inline`, `form-control`, `input-group`, `form-check`, `btn`) for collecting user information, demonstrating practical application of Bootstrap form elements.
* **Custom Styling:** While heavily reliant on Bootstrap, the project also links to an external `stylesheet.css` for custom styling, illustrating the ability to extend and override Bootstrap's default styles.
