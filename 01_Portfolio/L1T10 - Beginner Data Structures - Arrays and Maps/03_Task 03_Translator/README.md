# Simple English-Afrikaans Translator

A JavaScript application that functions as a basic dictionary, allowing users to translate a selection of English words into Afrikaans. This project demonstrates the use of JavaScript's `Map` data structure for storing key-value pairs, along with interactive loops and conditional logic to facilitate a continuous translation experience.

## 🌟 Features

* **Interactive Translation:** Prompts the user to select a word from a predefined list for translation.
* **`Map` Data Structure:** Utilizes a `Map` to efficiently store and retrieve English-Afrikaans word pairs.
* **Continuous Operation:** Employs a `while` loop to allow multiple translations in a single session until the user chooses to exit.
* **Input Validation:** Checks if the user-entered word exists in the dictionary, prompting for correct spelling if not found.
* **User Control:** Provides an option for the user to translate another word or exit the application.
* **Browser-Based Interaction:** Leverages standard browser `prompt()` and `alert()` functions for user input and displaying translations.

## 🚀 How to Run the Project

This project runs interactively in a web browser.

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd simple-translator # Or whatever your project folder is named
    ```
2.  **Open in Browser:** Locate the `index.html` file (assuming you have one linked to `more_loops.js`) in the project directory.
    * You can simply drag and drop the `index.html` file into an open Google Chrome (or any modern web browser) window.
    * Alternatively, double-click the `index.html` file, and it should open in your default browser.
3.  **Follow Prompts:** Once the page loads, interactive prompts will appear. Select a word to translate and follow the instructions.
4.  **Translate & Continue/Exit:** The translation will be displayed in an alert box. You will then be asked if you wish to translate another word.
