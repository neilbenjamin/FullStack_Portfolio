# Childhood Memories Web Page (Basic HTML Structure)

This project is a simple static web page built entirely with HTML, designed to showcase fundamental HTML elements and their usage. The page, titled "Childhood," describes hobbies and toys, providing a clear demonstration of structuring content, formatting text, embedding images, and implementing internal page navigation.

## 🌟 Features

* **Standard HTML Structure:** Follows best practices with `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>` tags.
* **Metadata:** Includes essential `<meta>` tags for character set (`UTF-8`) and responsive design (`viewport`).
* **Page Title:** Sets a clear `<title>` that appears in the browser tab.
* **Semantic Headings:** Uses `<h1>` and `<h2>` tags to organize content into logical sections (Hobbies, Toys).
* **Text Formatting:** Demonstrates various inline text-level semantics, including:
    * **Strong Importance:** `<strong>`
    * **Bold Text:** `<b>`
    * **Emphasis:** `<em>`
    * **Subscript:** `<sub>`
    * **Superscript:** `<sup>`
    * **Line Breaks:** `<br />`
* **Image Inclusion:** Embeds local images using the `<img>` tag, specifying `src` (relative path), `alt` text for accessibility/SEO, and `height` for dimensions.
* **Internal Navigation:** Implements an anchor link (`<a>` tag with `href="#top"`) to allow users to quickly jump back to the top of the page.
* **Code Comments:** Extensive HTML comments are used throughout the document to explain the purpose of each section and element, making it easy to understand for learners.

## 🚀 How to Run the Project

This project is a static HTML file and can be opened directly in any modern web browser.

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd childhood-memories-webpage # Or whatever your project folder is named
    ```
2.  **Open in Browser:** Locate the `index.html` file (or whatever your HTML file is named) in the project directory.
    * Simply drag and drop the `index.html` file into an open tab of your web browser (e.g., Google Chrome, Firefox, Edge).
    * Alternatively, you can double-click the `index.html` file, and it will typically open in your default web browser.
3.  **Explore the Page:** Once opened, you will see the "Childhood" web page displaying hobbies and toys with formatted text and images. You can use the "Back To Top" link to navigate.
