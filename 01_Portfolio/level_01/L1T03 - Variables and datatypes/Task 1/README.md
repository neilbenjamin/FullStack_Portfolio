# JavaScript Variables & Operations Exploration

A fundamental JavaScript project focused on demonstrating variable declaration, basic arithmetic operations, string manipulation, and type casting. This script is designed to be executed directly in a JavaScript runtime environment (like Node.js) and outputs all results to the console.

## 🌟 Features

* **Variable Declaration:** Demonstrates the declaration and assignment of `number`, `string`, and `boolean` data types.
* **Arithmetic Operations:** Performs and displays results of multiplication, addition, and modulo operations using numerical variables.
* **String Manipulation:** Shows string concatenation and the use of template literals for dynamic string creation.
* **Type Casting:** Illustrates casting a number to a boolean type.
* **Console Output:** All computational results and formatted messages are printed directly to the console for inspection.

## 🚀 How to Run the Project

This project runs directly in a JavaScript console environment, such as Node.js.

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd js-variables-operations # Or whatever your project folder is named
    ```
2.  **Install Node.js (if you don't have it):** If you don't already have Node.js installed on your system, you'll need it to run JavaScript files directly from your terminal. You can download it from [Node.js Official Website](https://nodejs.org/).
3.  **Execute the Script:** Open your terminal or command prompt, navigate to the project directory where `myVariables.js` is located, and run the script using Node.js:
    ```bash
    node myVariables.js
    ```
4.  **Check Console Output:** The results of the script's `console.log()` statements will be displayed directly in your terminal.
