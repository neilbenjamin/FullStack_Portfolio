# Multiple Choice Quiz

An interactive JavaScript-based multiple-choice quiz that challenges the user with a question and provides immediate feedback. The quiz allows users to retry until they select the correct answer or choose to quit.

## 🌟 Features

* **Interactive Quiz:** Presents a multiple-choice question and waits for user input.
* **Looping Attempts:** Allows the user to repeatedly guess the answer until correct, or opt to stop playing.
* **Instant Feedback:** Notifies the user whether their answer is correct or incorrect.
* **Play Again Option:** If an answer is incorrect, the user is prompted to try again.
* **Input Handling:** Converts user input to lowercase to ensure correct comparison regardless of initial casing.
* **Browser-Based Interaction:** Utilizes standard browser `alert()` and `prompt()` functions for welcome messages, questions, and feedback.

## 🚀 How to Run the Project

This project runs interactively in a web browser.

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd multiple-choice-quiz # Or whatever your project folder is named
    ```
2.  **Open in Browser:** Locate the `index.html` file (assuming you have one linked to `multiple_choice.js`) in the project directory.
    * You can simply drag and drop the `index.html` file into an open Google Chrome (or any modern web browser) window.
    * Alternatively, double-click the `index.html` file, and it should open in your default browser.
3.  **Follow Prompts:** Once the page loads, an alert will welcome you, followed by the multiple-choice question in a prompt. Follow the on-screen instructions in the browser to play the quiz.
