# Basic Calculator Application

This JavaScript project implements a simple command-line calculator that performs basic arithmetic operations: addition, subtraction, multiplication, and division. It takes two numbers and an operator as input from the user, validates the inputs, and then displays the computed result. The application is structured with separate functions for each operation, promoting modular and reusable code.

## 🌟 Features

* **Arithmetic Operations:** Supports addition, subtraction, multiplication, and division.
* **Modular Design:** Each arithmetic operation is encapsulated within its own dedicated function.
* **Interactive Input:** Prompts the user for two numbers and the desired operator.
* **Input Validation:** Checks if the entered numbers are valid numerical inputs and if the operator is one of the supported symbols (`+`, `-`, `*`, `/`).
* **Error Handling:** Provides user-friendly alerts for invalid inputs, guiding the user to re-enter correct values.
* **Looping for Robust Input:** Utilizes a `while` loop to ensure valid inputs are received before performing calculations.
* **Browser-Based Interaction:** Leverages standard browser `prompt()` and `alert()` functions for user interaction and displaying results.

## 🚀 How to Run the Project

This project runs interactively in a web browser.

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd basic-calculator # Or whatever your project folder is named
    ```
2.  **Open in Browser:** Locate the `index.html` file (assuming you have one linked to `function3.js`) in the project directory.
    * You can simply drag and drop the `index.html` file into an open Google Chrome (or any modern web browser) window.
    * Alternatively, double-click the `index.html` file, and it should open in your default browser.
3.  **Follow Prompts:** Once the page loads, interactive prompts will appear. Enter your first number, then your second number, and finally the operator you wish to use (`+`, `-`, `x`, or `/`).
4.  **View Result:** The calculated result will be displayed in an alert box.
