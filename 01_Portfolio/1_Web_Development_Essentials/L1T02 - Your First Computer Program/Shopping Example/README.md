# Simple Shopping List

A straightforward interactive web page built using **JavaScript** and **HTML** to create a basic grocery or shopping list. This project demonstrates sequential user input using `prompt()` and displaying formatted output using `console.log()`.

## 🌟 Features

* **Sequential Input:** Guides the user through entering three distinct items for their list.
* **Consolidated List:** Collects all user-entered items and presents them as a single, organized list.
* **Console Output:** The complete shopping list is clearly displayed in the browser's developer console.

## 🚀 How to Run the Project

Follow these simple steps to interact with the project:

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd simple-shopping-list # Or whatever your project folder is named
    ```
2.  **Open in Browser:** Locate the `index.html` file in the project directory.
    * You can simply drag and drop the `index.html` file into an open Google Chrome (or any modern web browser) window.
    * Alternatively, double-click the `index.html` file, and it should open in your default browser.
3.  **Follow Prompts:** Once the page loads, interactive prompts will appear. Follow the on-screen instructions in the browser to enter your grocery items.
4.  **Check Console:** Open your browser's developer console (usually by pressing `F12` or right-clicking and selecting "Inspect" -> "Console") to view your completed shopping list.
