# Hello User!

A very simple interactive web page built using **JavaScript** and **HTML** that prompts the user for their name and age, then displays a personalized greeting. This project demonstrates basic JavaScript input/output using `prompt()` and `console.log()`.

## 🌟 Features

* **User Input:** Prompts the user to enter their name and age.
* **Personalized Greeting:** Displays a greeting message incorporating the user's name and age.
* **Console Output:** The greeting is logged to the browser's console.

## 🚀 How to Run the Project

Follow these simple steps to interact with the project:

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd hello-user # Or whatever your project folder is named
    ```
2.  **Open in Browser:** Locate the `index.html` file in the project directory.
    * You can simply drag and drop the `index.html` file into an open Google Chrome (or any modern web browser) window.
    * Alternatively, double-click the `index.html` file, and it should open in your default browser.
3.  **Follow Prompts:** Once the page loads, interactive prompts will appear. Follow the on-screen instructions in the browser.
4.  **Check Console:** Open your browser's developer console (usually by pressing `F12` or right-clicking and selecting "Inspect" -> "Console") to see the final output message.

## 📝 Notes

* You might notice that the letter "I" in the console output sometimes appears slightly misaligned compared to other characters. This is a common rendering quirk with certain fonts or console implementations and does not affect the program's functionality.
