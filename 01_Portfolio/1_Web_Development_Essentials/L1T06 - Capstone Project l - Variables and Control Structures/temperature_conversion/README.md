# Temperature Converter

A simple and interactive temperature converter built using **JavaScript** and **HTML**. This tool is designed to provide quick and easy conversions between Celsius (°C), Fahrenheit (°F), and Kelvin (K) units.

## 🌟 Features

* **Bidirectional Conversion:** Convert temperatures seamlessly from:
    * Celsius (°C)
    * Fahrenheit (°F)
    * Kelvin (K)
* **Interactive Prompts:** The script guides the user through the conversion process by prompting for:
    1.  The **temperature unit** they are converting *from* (`C`, `F`, `K`).
    2.  The **temperature value** to convert.
    3.  The **unit** they want to convert *to* (`C`, `F`, `K`).
* **Instant Results:** The calculated conversion is immediately displayed in an alert box.
* **Input Validation:** Robust validation ensures that only valid temperature units (`C`, `F`, `K`) and numerical values are accepted, preventing errors.

## 🚀 How to Run the Project

Follow these simple steps to use the Temperature Converter:

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd temperature-converter # Or whatever your project folder is named
    ```
2.  **Open in Browser:** Locate the `index.html` file in the project directory.
    * You can simply drag and drop the `index.html` file into an open Google Chrome (or any modern web browser) window.
    * Alternatively, double-click the `index.html` file, and it should open in your default browser.
3.  **Follow Prompts:** Once the page loads, an interactive prompt will appear. Follow the on-screen instructions in the browser to perform your temperature conversions.

Enjoy converting temperatures!
