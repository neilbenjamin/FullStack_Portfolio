# Recursive String Reverser

A JavaScript project that showcases the concept of recursion by implementing a function to reverse a given string. The `reverseSent()` function breaks down the problem of string reversal into smaller, self-similar sub-problems, building the reversed string character by character through recursive calls until a base case is met.

## 🌟 Features

* **Recursive Implementation:** Demonstrates how to write a function that calls itself to solve a problem.
* **String Reversal:** Effectively reverses the order of characters in any input string.
* **Base Case Handling:** Clearly defines a stopping condition for the recursion (`index < 0`) to prevent infinite loops.
* **Character Concatenation:** Builds the reversed string by sequentially adding characters from the original string in reverse order.
* **Console Output:** Prints the original and recursively reversed string directly to the console.

## 🚀 How to Run the Project

This project is designed to be executed directly in a JavaScript runtime environment, such as Node.js.

1.  **Clone or Download:** Obtain the project files by cloning this repository or downloading it as a ZIP file.
    ```bash
    git clone [Your Repository URL Here]
    cd recursive-string-reverser # Or whatever your project folder is named
    ```
2.  **Install Node.js (if you don't have it):** If you don't already have Node.js installed on your system, you'll need it to run JavaScript files directly from your terminal. You can download it from [Node.js Official Website](https://nodejs.org/).
3.  **Execute the Script:** Open your terminal or command prompt, navigate to the project directory where `recursion1.js` is located, and run the script using Node.js:
    ```bash
    node recursion1.js
    ```
4.  **Check Console Output:** The reversed version of the `sampleSentence` will be displayed directly in your terminal.
